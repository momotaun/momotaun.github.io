# momotaun.github.io

Personal portfolio site for Moeketsi Motaung, served at [moeketsimotaung.me](https://moeketsimotaung.me).

Built with React (Vite) and Tailwind CSS. Deployed automatically to GitHub Pages via GitHub Actions on push to `main`.

## Branching

- `main` — production, auto-deploys on push
- `develop` — integration branch
- `feature/*`, `fix/*`, `chore/*` — work branches off `develop`

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
